# New developer

If you are a completely new developer at CGI, go to [this page](https://eu.sharepoint.ent.cgi.com/sites/CL16586/Shared%20Documents/CGI%20devloper%20guides) and follow the instructions found there. Once you are done with those, return to this document.

## Common softwares

For this project, we strive to use same/similar softwares for each developer to facilitate smooth and ergonomic shared developer practices. Below is a list of common softwares used in this project

- WSL2 (Windows users only)
- OpenAI ChatGPT and Codex
- Rancher Desktop (GUI for Docker)

**We do not want to force anyone to use these softwares!** However, due to various reasons, **it is highly recommend** to install and use these softwares if they fulfill a need of yours. Installation steps and the reasoning for the choice of software in their respective use case is explained under the subheading for software separately.

If you have opinions on other softwares that you strongly want to use that conflict with a software listed here, you are encouraged to discuss it with your team leader!
