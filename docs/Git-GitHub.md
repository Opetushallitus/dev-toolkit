# Git/Github

## Common guidelines

When using Git, here are some common guidelines

- When opening up a new branch and working on a ticket, use the ticket identifier as a prefix to the branch. For example, if the ticket is identified as `TICKET-123`, then name your branch `TICKET-123_<some text>`. You can replace `<some text>` with whatever text you want, or omit it completely.
