# OPH Project Dev-Toolkit

The purpose of this dev-toolkit is to

1. Gather relevant developer documentation in an ergonomic and convenient manner
2. Keep and maintain common configuration files across projects, e.g. dotfiles, github repository specific files
3. Keep and maintain templates used across projects

## Maintainer

*All developers*.

## Getting started

This repository contains documentation, shared configuration files, and templates. No application setup, build tools, or running services are required to use it.

If you are a new developer, follow the guidelines found in the [new developer](./general-docs/new-developer.md) documentation.

Browse the documentation and copy configuration files or templates into your project as needed, adapting them to the project's requirements:

- [General developer documentation](./general-docs/new-developer.md): onboarding and links to common tools.
- [Shared configurations and templates](./configs/README.md): common configuration files and repository templates, including the [README template](./configs/README_TEMPLATE.md).
- [YK documentation](./YK/README.md): guidance specific to Yleiskäyttöiset Palvelut services.
- [OVP documentation](./OVP/README.md): guidance specific to Opiskelijavalinta services.
- [eHoks documentation](./eHoks/README.md): guidance specific to eHoks services.
- [ePerusteet documentation](./ePerusteet/README.md): guidance specific to ePerusteet services.
