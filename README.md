# OPH Project Dev-Toolkit

The purpose of this dev-toolkit is to

1. Gather relevant developer documentation in an ergonomic and convenient manner
2. Keep and maintain common configuration files across projects, e.g. dotfiles, github repository specific files
3. Keep and maintain templates used across projects

## Important links

If you are a new developer, follow the guidelines found in the [new developer](./docs/new-developer.md) documentation.

If you need to find internal CGI developer guides, go to [this page](https://eu.sharepoint.ent.cgi.com/sites/CL16586/Shared%20Documents/CGI%20developer%20guides).

For the Confluence developer portal, go to [this page](https://wiki.eduuni.fi/pages/viewpage.action?pageId=819431935&spaceKey=KEIJO&title=Ohjeita%2Bkehitt%C3%A4jille%2BKehitt%C3%A4j%C3%A4portaali).
