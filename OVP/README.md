# OVP

Documentation specific to the Opiskelijavalinta Palvelut (OVP) services.

## Maintainer

_All developers_.

## Getting started

Start with the [new developer guide](../general-docs/new-developer.md) for onboarding and common tools, and see the [dev-toolkit overview](../README.md) for shared documentation and internal developer resources.

Read the [ticket lifecycle guide](./ticket-lifecycle.md) for the workflow from starting a ticket through review, testing, and production deployment. Linked internal resources require access to the relevant systems and repositories.

This directory contains documentation and requires no application setup or running services. For instructions on running or testing an individual OVP service, refer to that service's repository.
